# DjangoProject-6

В данной работе мы создаём проект интернет-магазина, который будем дорабатывать на каждом уроке в течении курса.
Данный проект послужит составляющей моего портфолио.

## Установка
1. Клонируйте репозиторий по следующей ссылке [GitHub](<https://github.com/Tishina-az/DjangoProject-6.git>).

2. Установите зависимости:
    ```
    poetry install
    ```

## Логика проекта
1. В приложении `catalog` реализованы следующие контроллеры:
   - отображение страниц **home.html** и **contacts.html**;
   - форма обратной связи на странице **contacts.html**.
2. ... 

## Статические файлы
Статические файлы хранятся в корне проекта, в директории `static`.

## Проверка работы
1. Запустите сервер:
```
python manage.py runserver
```
2. Перейдите по [ссылке](<http://127.0.0.1:8000>) в данном файле или терминале.
